# Airbnb Listing Clone

A React + Vite + Tailwind CSS recreation of the reference listing page at
`https://airbnb-clone-umber-two.vercel.app/`, built from screenshots of the
Listing, Photo Tour, Amenities, Reviews, and Location views.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview   # serve the production build locally
```

## Deploy

Push this folder to a GitHub repo and import it into Vercel or Netlify —
no configuration needed (Vite's default build output is `dist/`).

## Notes

- Photos are placeholder images from picsum.photos, seeded per room/category
  so they're stable. Swap the `img()` seeds in `src/data/listing.js` for real
  photography before shipping.
- The lightbox (single-photo viewer with prev/next + keyboard arrows + Esc to
  close) wasn't visible in the reference screenshots I was given, so its
  visual style is inferred from the rest of the site rather than copied
  directly.
